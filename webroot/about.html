About the Project

A web server implemented from scratch in Java

Technology

Built using Java, ServerSocket, Socket, input/output streams and Java NIO file APIs.

Architecture

The server accepts incoming connections, processes HTTP requests and sends HTTP responses using a dedicated worker thread.

Security

The server validates requested paths and prevents directory traversal outside the webroot directory.

HTTP Support

The server currently supports HTTP GET requests and HTTP/1.0 and HTTP/1.1 request formats.
